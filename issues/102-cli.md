# 102 — CLI: flags + subcommands

**Labels:** feature, cli
**Milestone:** 2 — Reach

## Context

Configuration is env-only. A thin CLI makes the binary self-documenting and easier to wire into any MCP client config (args instead of env blocks). Stdlib `flag` + an `os.Args[1]` switch is enough — no cobra/urfave unless the command tree actually grows.

## Commands

- `nodered-mcp` / `nodered-mcp serve` — run the server (default)
- `nodered-mcp version` — print version (set via `-ldflags`)

## Flags (override env, env overrides defaults)

- `--url` (NODERED_URL), `--token` (NODERED_TOKEN)
- `--transport` (MCP_TRANSPORT), `--http-addr` (MCP_HTTP_ADDR)
- `--log-level` (LOG_LEVEL)
